= **`+driftmap+`** -- __YAML drift detection__

**DriftMap** reports the _drift_ between two sets of YAML configuration. It flattens
each side to dotted key paths and shows which values were changed, added, or removed.

It is built for two workflows in particular:

* **Helm chart values** -- compare two `values.yaml` files (for example
  `values-dev.yaml` vs `values-prod.yaml`) to see exactly which chart values differ
  between environments or releases.
* **Vault secrets** -- compare two directories of secrets that were pulled down as
  YAML files with `vaultsync` (https://github.com/kriipke/vaultsync[kriipke/vaultsync]),
  for example a `before/` and `after/` snapshot, to audit what changed across a sync.

`A` and `B` may both be *files* (single-file diff) or both be *directories*
(recursive, per-file diff). You can also compare a path between two git refs with
`--from`/`--to`/`--path`.

=== Install

[source,shell]
----
$ go install github.com/kriipke/driftmap/cmd/cli@latest
# installs a `cli` binary; rename to `driftmap`, or build locally:
$ make build-cli   # produces ./driftmap
----

=== Usage

```
driftmap [A] [B] [flags]

Arguments:
  A, B    Two values.yaml files, or two directories of YAML files.
          Both must be files, or both must be directories.

Flags:
  -o, --output string   Output format: 'shell' (default), 'yaml', or 'columns'
      --from string     Git ref/tag/commit for the base (used with --to and --path)
      --to string       Git ref/tag/commit for the target (used with --from and --path)
      --path string     Compare all YAML files under this path between --from and --to
  -h, --help            Show help

Examples:
  # Compare two Helm values files
  driftmap ./tests/values-dev.yaml ./tests/values-prod.yaml

  # Compare two directories of vaultsync-exported secrets
  driftmap ./vault-before ./vault-after

  # Compare a chart directory between two git refs
  driftmap --from v1.2.0 --to v1.3.0 --path charts/app
```

==== Compare Two Directories of Vault Secrets

Given two directories of YAML files exported by `vaultsync`, DriftMap reports a
per-file summary of changed, added, and removed files:

[source,shell]
----
$ driftmap ./vault-before ./vault-after
Changed files:

# db.yaml
password: old → new

Added files:
  sub/new-service.yaml

Removed files:
  legacy-token.yaml
----

=== Run as a Service

From the root of the repository:

==== Start the Server

[source,shell]
----
$ go run cmd/api/main.go
2025/07/30 05:25:48 Starting web server on :8080
----

==== Validate Availability

Again, from the root of the repository:

[source,shell]
----
$ curl -sSd @tests/testdata.json http://localhost:8080/diff | jq

{
  "variables": [
    {
      "name": "key",
      "default": "value",
      "value": "newvalue",
      "status": "changed"
    }
  ]
}
----

=== Run as a Container

From the root of the repository:

[source,shell]
----
$ docker build -t driftmap-api .
----

[source,shell]
----
$ docker run --rm -p "8080:8080" driftmap-api
----
